# 逐个检查并添加正确的语言标识符 (yaml/bash/text/promql)
```

#### A-2：交叉引用格式全书不统一

当前至少存在 **5 种**引用风格混用：

| 风格 | 示例 | 出现频率 |
|------|------|---------|
| 纯章号 | `第 4 章` | 高 |
| 章号+节号 | `第 2 章 §2.6.3` | 中 |
| 西式节号 | `（§5.2.4）` | 中 |
| 中式节号 | `第 5.5.2 节` | 低 |
| 缩写 | `ch2/ch3` | 仅 ch19 |

**建议统一为**：
- 引用章：`第 N 章`
- 引用节：`第 N 章 §N.M`
- 引用小节：`§N.M.X`

```bash
# 搜索不规范的引用格式
grep -Pn "第 \d+\.\d+ 节" *.md        # 中式节号
grep -Pn "ch\d+" *.md                   # 缩写格式
```

#### A-3：提示框 Callout 体系混乱

全书 `> ` 引用块的前缀命名极不统一：

| 现状 | 出现的变体 |
|------|----------|
| 核心认知类 | `> **核心认知**：` / `> **关键认知**：` / `> 认知：` |
| 警告类 | `> **注意**：` / `> ⚠️ **生产必配**：` / `> ⚠️ **证书默认 1 年**` |
| 决策类 | `> **决策逻辑**：`（相对统一） |
| 排障类 | `> **排障关联**：`（有时混在正文中） |

**建议统一为 4 种标准 Callout**：

```markdown
> **核心认知**：解释底层原理或关键概念
> **决策逻辑**：选型对比与技术决策
> **⚠️ 生产避坑**：陷阱、反模式、常见错误
> **排障关联**：故障排查相关指引
```
